# БотаникАрт Каталог

Закрытая мобильная панель `/catalogue/`. На iPhone: открыть в Safari, «Поделиться» → «На экран Домой». Вход сохраняется на 30 дней; выход или смена пароля прекращают сессию.

## Данные

Единый рабочий каталог хранится в `api/.private/catalogue/catalogue.sqlite`. Он недоступен по HTTP и не загружается в GitHub. Снимок Flowwow из `data/catalog.json` импортируется в базу при изменении его содержимого. Публикация файлов не заменяет базу, фотографии, пароль или заказы.

- `flowwow`: содержание карточки обновляет Flowwow, в панели меняется только видимость.
- `avito`: разовый импорт; описание, цена, фотографии и наличие редактируются в панели. Автоматических запросов к Авито нет.
- `manual`: товары, добавленные в панели; внутреннее происхождение ручной карточки.

Флаг скрытия находится отдельно от исходного содержимого. Обновление Flowwow его сохраняет. Пропавшая из полного снимка Flowwow карточка остаётся в панели, но скрывается с сайта. Возвращение того же ID восстанавливает связь, сохраняя локальное скрытие. Ручные записи не затрагиваются обновлением Flowwow. Объявления Авито с одинаковым ID нельзя импортировать повторно.

Сайт получает каталог через `/api/catalog.php`. Платёжный обработчик использует ту же базу: скрытая карточка недоступна для новой покупки, цена сверяется с текущей серверной записью.

Перед первым изменением за день создаётся резервная копия SQLite, сохраняются последние 14 копий. Полную базу и `assets/uploads/catalogue` также включать в резервирование хостинга. Физического удаления товаров в панели нет: используется обратимое скрытие.

## Вход

На сервере: `php /полный/путь/public_html/api/.private/configure-catalogue.php`. Логин запрашивается открыто; пароль и его подтверждение — скрыто. Хранится хеш пароля. Реальные данные входа не включать в код и GitHub.

PHP: PDO SQLite, GD, mbstring. Доступ только по HTTPS. Сессии HttpOnly, Secure, SameSite=Strict; изменения требуют CSRF-токен. Есть ограничение попыток входа и защита от перезаписи устаревшей версии карточки.

## Импорт Авито

Прямое открытие Авито заблокировано политикой безопасности браузерного инструмента. Для переноса нужны предоставленные владельцем тексты/фотографии или сохранённые файлы объявлений. Один набор материалов соответствует одному постоянному ID. Перед публикацией сверять комплектность, цену, наличие и возможное совпадение с Flowwow. Не публиковать карточки с вымышленными описаниями или фотографиями.

## Площадки публикации

Происхождение `source` остаётся внутренним и определяет право редактировать содержимое. Метки в интерфейсе зависят от `product_channels`: можно включить Авито и Flowwow одновременно. «Сайт» показывается только для видимой локальной карточки без выбранных внешних площадок. Для скрытой карточки без площадок показывается «Не опубликован».

Для новых площадок сохраняются отдельные цена, заголовок и описание. Пустое поле наследует данные сайта. Настройки находятся отдельно от документа товара и не сбрасываются обновлением Flowwow. Изменения и очередь намерений сохраняются одной транзакцией. Очередь объединяет повторные правки одного товара и площадки; старые импортированные объявления автоматически не отправляются и не снимаются.

Реальная отправка на внешние площадки ещё не активирована. `MarketplaceService` подготавливает проверяемый пакет и XML по будущему подтверждённому шаблону Авито. Публичный URL фида и рабочий отправитель Flowwow будут подключены после проверки шаблона, доступа и одного товара. Выбор галочки сейчас означает сохранённое намерение, а не подтверждённую публикацию.

Настройки доступа размещаются только в `api/.private/marketplaces-config.php` по примеру `marketplaces-config.example.php`. Этот файл исключён из публикации и не должен попадать в Git. Секреты не возвращаются браузеру. Проверка Авито использует получение токена и чтение автозагрузок; никакие объявления этим не изменяются. При отсутствии ключей запросы не выполняются. Проверки ограничены одним разом в пять минут с серверной блокировкой параллельных запросов.

В «Площадки» задаётся дата следующего продления подписки. Напоминания при открытом приложении появляются за семь и три дня, отдельно подтверждаются и повторно не показываются на той же стадии. Календарь использует Москву. При закрытом приложении push-уведомлений нет. Дата оплаты не определяется по концу календарного месяца; после продления нужно указать новую дату.

Отказ доступа Авито показывается красной плашкой с предложением проверить подписку, ключи и права. Таймаут сети и ограничение частоты запросов показываются отдельно и не объявляются неоплаченной подпиской.
