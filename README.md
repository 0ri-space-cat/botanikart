## Синхронизация каталога Flowwow

1. GitHub Actions по расписанию и вручную обращается к официальному API.
2. POST https://apis.flowwow.com/apiseller/products?shopId=257704 с параметрами withArchive=true, extended=true и пагинацией.
3. Сопоставляет productId и исходные URL с уже сохранёнными карточками. Сохраняет правки оформления и переводы статусов отдельно от исходных полей.
4. Обновляет каталог и фотографии. При ошибках сохраняет последнюю успешную версию; пустой или неполный ответ не заменяет рабочий каталог.
5. На текущей основной ветке сайт пока публикуется прежним workflow GitHub Pages; миграция сайта в Yandex Object Storage готовится отдельно в `yandex-cloud-migration`.
6. Хранит ключ в GitHub Actions Secrets, а не в браузерном коде или репозитории.

Загрузка архива сама по себе не означает, что каждый архивный товар доступен для повторения: правило «Под заказ» нужно применять к согласованным позициям, а удалённые служебные карточки скрывать отдельно.

Автосинхронизация настроена в `.github/workflows/pages.yml`: запуск каждый час и вручную. Ключ хранится в Actions Secret `FLOWWOW_API_KEY`. Первая успешная выгрузка: 139 записей API; сайт показывает 53 карточки, из них 42 доступны и 11 отмечены «Под заказ». При ошибке API текущая версия каталога сохраняется. GitHub может приостанавливать расписание в неактивных публичных репозиториях, поэтому периодически проверяйте вкладку Actions.

## Покупка и публикация

- Обновлены заголовки, контакты и адрес (офис 10), фотография студии и печать с листом. Кнопки и нижний блок стали светлее. Убраны все стрелки в правый верхний угол.
- «Купить флорариум» открывает выбранный товар с ценой и кнопкой «Купить». Платёжная функция подготовлена для Yandex Cloud Functions; её развёртывание и банковская проверка ещё не подтверждены.
- Рабочая схема размещения: сайт — Yandex Object Storage; обработка платежей — Yandex Cloud Function; GitHub — исходный код и синхронизация Flowwow. GitHub Pages не является целевой площадкой для интернет-магазина.
- Рабочие ключи терминала и настройки кассового чека должны храниться в защищённых секретах облака, не в сайте, репозитории или ZIP.
- Сумма на сайте покрывает только товар. Самовывоз бесплатный; курьер, Яндекс Доставка или СДЭК оформляются отдельно через Telegram после оплаты товара, стоимость согласуется отдельно.
- Flowwow Seller API проверен успешным запуском GitHub Actions. Секрет API хранится в настройках репозитория и не включён в сайт.
- Вебхуки Flowwow для обновления каталога не нужны: он синхронизируется по расписанию. Уведомления Т-Банка об оплате потребуют отдельного серверного обработчика.


Для Yandex Object Storage подготовлены `scripts/build-site.py` и ручной workflow `.github/workflows/deploy-yandex-storage.yml`. Сборка берёт только публичные страницы, конфигурацию сайта и фотографии, перечисленные в каталоге; приватные файлы и исходники платежной функции не попадают в бакет. Перед первым запуском нужно создать бакет и отдельный сервисный аккаунт с ключом доступа, затем сохранить `YC_STORAGE_BUCKET`, `YC_STORAGE_ACCESS_KEY_ID` и `YC_STORAGE_SECRET_ACCESS_KEY` в GitHub Actions Secrets.
