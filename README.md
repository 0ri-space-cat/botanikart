# БотаникАрт

Лендинг студии, каталог Flowwow и покупка через Т-Банк. Целевая площадка — обычный виртуальный хостинг **Timeweb с PHP 8.3+**. Домен — botanikart.ru.

## Подключение

Действующая инструкция: [hosting/SETUP.md](hosting/SETUP.md).

Сайт размещён на Timeweb: https://botanikart.ru/; технический адрес https://cd831058.tw1.ru/ сохранён. SSH и автоматическая публикация настроены. Банковские ключи хранятся в закрытой служебной папке с запретом прямого HTTP-доступа; GitHub их не получает. DEMO-покупка проверена до статуса CONFIRMED и возврата на сайт. Сервис «Чеки Т-Бизнеса» и рабочие ключи подключены. Рабочая платёжная форма открывается; реальное списание владелец решил не проверять.

## Состав проекта

- index.html, catalog.html, style.css, script.js — сайт;
- assets/ — фотографии и согласованный логотип;
- data/catalog.json и catalog.js — единый каталог;
- scripts/sync-flowwow.py — официальный Flowwow Seller API;
- catalogue/ — закрытое веб-приложение «БотаникАрт Каталог», установка на экран iPhone;
- hosting/private/CatalogStore.php — единая серверная база товаров и локальная видимость;
- api/ — публичные PHP-точки создания платежа, статуса и уведомлений;
- hosting/private/ — обработчик, шаблон закрытой конфигурации и команды настройки;
- offer.html и privacy.html — условия продажи и обработка персональных данных;
- .github/workflows/timeweb.yml — синхронизация и публикация по SFTP;
- scripts/package-timeweb.py — ZIP для файлового менеджера.

## Каталог и заказы

Flowwow содержит около 53 карточек; разовый импорт Авито добавил товары и варианты, общий публичный каталог содержит около 119 позиций. Выбранные распроданные композиции остаются под заказ. Описания получают абзацы и списки без переписывания исходного текста. Flowwow синхронизируется каждый час; последняя успешная версия сохраняется при ошибке API. Ключ FLOWWOW_API_KEY уже хранится в GitHub Secrets.

Заказы и резервы хранятся в защищённой api/.private: прямой HTTP-доступ запрещён, файлы данных дополнительно защищены PHP-командой exit. Сервер защищает от повторной оплаты одного экземпляра на нашем сайте. Автоматическое уменьшение остатков Flowwow при продаже на сайте ещё не реализовано: остатки двух площадок сверяются владельцем.

## Проверка и сборка

```sh
php hosting/tests/payments.php
python3 scripts/build-site.py --output /абсолютный/путь/новая-папка
python3 scripts/package-timeweb.py /абсолютный/путь/botanikart-timeweb.zip
```

Статический предпросмотр: python3 -m http.server 8765 --bind 127.0.0.1. Python не исполняет PHP; платёжный обработчик проверяется отдельно через PHP.
