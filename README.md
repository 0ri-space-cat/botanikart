# БотаникАрт

Лендинг студии, каталог Flowwow и покупка через Т-Банк. Целевая площадка — обычный виртуальный хостинг **Timeweb с PHP 8.3+**. Домен — botanikart.ru.

## Подключение

Действующая инструкция: [hosting/SETUP.md](hosting/SETUP.md).

Для загрузки нужны SSH-сервер, логин и абсолютная папка public_html. Банковские ключи вводятся в скрытый ввод на хостинге и хранятся вне веб-корня. GitHub их не получает. Публикация на Timeweb ещё не выполнена: ожидаем доступ к хостингу. Покупка включается после банковского DEMO-теста.

## Состав проекта

- index.html, catalog.html, style.css, script.js — сайт;
- assets/ — фотографии и согласованный логотип;
- data/catalog.json и catalog.js — единый каталог;
- scripts/sync-flowwow.py — официальный Flowwow Seller API;
- api/ — публичные PHP-точки создания платежа, статуса и уведомлений;
- hosting/private/ — обработчик, шаблон закрытой конфигурации и команды настройки;
- offer.html и privacy.html — условия продажи и обработка персональных данных;
- .github/workflows/timeweb.yml — синхронизация и публикация по SFTP;
- scripts/package-timeweb.py — ZIP для файлового менеджера.

## Каталог и заказы

Текущий снимок содержит 53 карточки. Выбранные распроданные композиции остаются под заказ. Описания получают абзацы и списки без переписывания исходного текста. Flowwow синхронизируется каждый час; последняя успешная версия сохраняется при ошибке API. Ключ FLOWWOW_API_KEY уже хранится в GitHub Secrets.

Заказы и резервы хранятся вне публичной папки. Сервер защищает от повторной оплаты одного экземпляра на нашем сайте. Автоматическое уменьшение остатков Flowwow при продаже на сайте ещё не реализовано: остатки двух площадок сверяются владельцем.

## Проверка и сборка

```sh
php hosting/tests/payments.php
python3 scripts/build-site.py --output /абсолютный/путь/новая-папка
python3 scripts/package-timeweb.py /абсолютный/путь/botanikart-timeweb.zip
```

Статический предпросмотр: python3 -m http.server 8765 --bind 127.0.0.1. Python не исполняет PHP; платёжный обработчик проверяется отдельно через PHP.
